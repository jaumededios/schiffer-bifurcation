# Introductory figures

`computer-assisted-domain-solution.png`, `n28-domain-solution.png`, and
`scalloped-objects.png` are shared with the
[joint Schiffer–Pompeiu exposition](https://pompeiu-schiffer.org). They were
copied from that site on 2026-08-27 so that this static site does not depend on
an external image host at runtime.

The first two images show the computer-assisted and bifurcation Schiffer
domains with their eigenfunctions. The third contains the Hong Kong two-dollar
coin and biscuit photographs used for the geometric comparison in the
introduction.

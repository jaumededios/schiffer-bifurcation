# Introductory figures

`n28-domain-solution.png` and `scalloped-objects.png` are shared with the
[joint Schiffer–Pompeiu exposition](https://pompeiu-schiffer.org). They were
copied from that site on 2026-08-27 so that this static site does not depend on
an external image host at runtime.

The first image shows a representative 28-fold Schiffer domain and its
eigenfunction. The second contains the Hong Kong two-dollar coin and biscuit
photographs used for the geometric comparison in the introduction.
